# Security policy

Please do not open a public issue with credentials, OAuth tickets, private
project data or a vulnerability that could expose customer data.

Report security concerns privately to the Wedding Studio operator through the
contact channel published on [locationsap.com](https://www.locationsap.com/).
Include a minimal reproduction, affected component and whether the issue is
local to the plugin package or the private MCP/backend service.

The plugin package contains no production credentials and no customer data.
